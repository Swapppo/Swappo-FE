# Swappo-FE

Mobile frontend for the Swappo platform built with React Native and Expo.

## Features

- **Cross-Platform**: iOS, Android, and Web support
- **React Navigation**: Native stack navigation
- **NativeWind**: Tailwind CSS for React Native
- **Image Picker**: Upload item photos
- **Secure Storage**: Token and credential management
- **Axios**: HTTP client for API integration

## Quick Start

### Installation

```bash
npm install
```

### Development

```bash
# Start Expo dev server
npm start

# Or platform-specific
npm run android
npm run ios
npm run web
```

## Tech Stack

- **React Native** 0.81.5
- **Expo** 54.0.0
- **React** 19.1.0
- **TypeScript** 5.9.2
- **NativeWind** (Tailwind CSS)
- **React Navigation** 7.x
- **Axios** for API calls
